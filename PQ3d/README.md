# PQ3D for SceneVerse++

This project is based on [PQ3D/PQ3D](https://github.com/PQ3D/PQ3D/tree/main) and is used for SceneVerse++ data processing and training.

For environment installation, please follow the original PQ3D repository instructions.

## 1. Data Generation

The configuration file is [`data_process/config.yaml`](data_process/config.yaml). It is used by the data generation stage.

### `process_dataset`

Controls which datasets will be processed in this run.

For example:

```yaml
process_dataset: [svpp, ScanNet]
```

means the scripts will process both `svpp` and `ScanNet`.

### Fields under `datasets`

The following fields are the most important:

- `data_root`: The root directory of the raw dataset. The scripts read each scene from here.
- `process_number`: The maximum number of scenes to process. Use `-1` to process all scenes.
- `segmentator_s`: The `s` parameter used by the segmentator. It affects the generated segment file name and the segmentation process.
- `segmentator_k`: The `k` parameter used by the segmentator. It affects the generated segment file name and the segmentation process.

Run the data generation script directly:

```bash
python data_process/generate_dataset.py
```

The script will read `data_process/config.yaml` and generate the intermediate files according to `process_dataset`.

## 2. Data Visualization

Visualize training data with:

```bash
python data_process/visulization.py --vis_training_data --dataset_name ScanNet
```

Argument explanation:

- `--vis_training_data`: Visualize training data, including point clouds and bounding boxes.
- `--dataset_name`: The dataset name to visualize. It must match a key under `datasets` in `config.yaml`, such as `svpp` or `ScanNet`.
- `--vis_segments`: Visualize segment results.
- `--scene_name`: Visualize only one scene. If omitted, the script will iterate over all scenes.
- `--config`: Path to the config file. The default is `data_process/config.yaml`.

Example:

```bash
python data_process/visulization.py \
  --vis_training_data \
  --dataset_name ScanNet \
  --scene_name scene0007_00
```

## 3. Directory Convention

By default, the generated data will be saved under the `save_root` specified in `config.yaml`. The output usually includes:

- `segments/`: Segment files generated by the segmentator
- `base/<dataset_name>/scan_data/`: Point clouds and instance labels
- `aux/<dataset_name>/segment_id/`: Resplit segment ids

If you change `config.yaml`, these paths will change accordingly.

## 4. Training

First train `svpp_gt`:

```bash
python run.py --config-path configs --config-name svpp_gt.yaml
```

After training finishes, run `svpp_gt_scannet_fps`:

```bash
python run.py --config-path configs --config-name svpp_gt_scannet_fps.yaml
```

Notes:

- Before the second-stage training, update `pretrain_ckpt_path` in `svpp_gt_scannet_fps.yaml` to point to the checkpoint saved by the first stage.
- If your checkpoint is not in the default output directory, set the path manually.
